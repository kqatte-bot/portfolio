# Портфолио Екатерины Федоровой

Сайт: https://kqatte-bot.github.io/portfolio/

Одна страница без сборки: `index.html` и картинки в `img/`.
Спираль работ по четырём направлениям, список проектов и страницы кейсов.

Чтобы поменять тексты кейсов, найди в `index.html` блок `<script id="data">`:
у каждого кейса есть поля `title`, `sub`, `lead`, `tags`, `inside`.
